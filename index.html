Overview

The poster examines how single and competing pure tones shape oscillation frequencies across a tonotopically arranged oscillator bank. Tonotopy is stimulus-dependent: the response at a given position depends on the input. Local parameter adaptation can improve target–masker separation, suggesting a possible role for efferent adaptation.

Model

A local transmission-line element with delayed active feedback is represented near a Hopf bifurcation by a Stuart–Landau oscillator. Coupling these elements yields a reduced model of the cochlear partition. The complex state η combines displacement and velocity.

η˙=(μ+jω0)η−(α+jβ)|η|2η+s(t)

Coupling between elements is added to each local oscillator equation.

Simulation setup & interpretation

Bank854 oscillators; 400 Hz–2 kHz; Greenwood spacing
Single toneConstant amplitude; μ = 0, α = 1, β = 1
Masker1.2 kHz; 84 dB above the target level
Local adaptationα = β = 0.1 for ten oscillators near the target; remaining oscillators unchanged

Rotation number

ρn=f¯nfstim

Mean oscillation frequency relative to the stimulus frequency. ρ = 1 indicates matching mean frequencies; ρ > 1 or ρ < 1 indicates faster or slower oscillation.
